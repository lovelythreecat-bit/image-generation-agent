# LangGraph 重构验收记录

## 实现范围

现有仓库原地迁移到真实 LangGraph StateGraph；桌面、CLI 与 Python API 共用图执行入口，覆盖原有平台、主图、详情组图及白底图。未保留第二套生产编排。

生成、保存候选、审核与修复分节点。审核服务异常重试已有候选，质量失败默认最多两轮定向修复；提示词保留原始身份权威，引用具体失败证据并保护已正确部分。功能声明不强制转成画面结构，商品原生印花仍需保真。

候选分别存放于 candidates、approved、accepted；自动成功候选迁移后从 candidates 移除。人工接受保留原审核记录及接受理由，不能伪装自动审核通过。

任务持久保存输入、候选、审核、阶段状态、SQLite 检查点和实际 POST 预算；恢复校验文件哈希与提交日志。已提交但响应未落盘的生图进入 generation_uncertain，拒绝自动重发，避免以“重试”为名重复收费。

## 使用与边界

运行 start-desktop.cmd 打开更新后的桌面入口；加载任务目录可查看候选和恢复审核。命令行新增 resume 和 accept，Python 暴露 resume_images 和 accept_candidate。

历史 v1 结果可查看，不支持恢复旧编排任务。无 output_dir 的内存调用不支持跨进程恢复。真实模型的保真、美观及供应商可用性不能由离线测试保证；真实多平台批量任务和手工桌面交互不属于本次单素材真实回归的证明范围。
