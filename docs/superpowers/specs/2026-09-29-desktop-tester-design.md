# 轻量桌面测试工具

用户已确认：Python/Tkinter 中文桌面，左侧参数、右侧预览和结果，复用当前 agent。

- 使用现有 Python 3.12+、Tkinter、Pillow，无新增运行依赖，无 HTTP 服务。
- 添加 1–8 张本地素材；输入商品名称、分类、brief；选择配置文件、模型别名、平台、输出、比例与尺寸。
- 配置文件列出各服务，密码框按服务覆盖密钥，仅保留在内存，不修改环境或配置文件。
- 分析和生成在独立 asyncio 工作线程运行；界面通过队列收取结果，防重复提交；取消与关闭等待任务清理。
- 展示分析 JSON、澄清选项；选择真实 option.selection 后携带原快照恢复生成。输入变化清除旧快照，文件字节变化由核心校验。
- 生成结果包含成功/部分成功/失败/待补充状态、图片预览、审核及错误 JSON；结果使用核心保存到独立目录。
- 窗口内显示状态和耗时，不伪造阶段进度。输入出错保留表单。
- 提供项目根目录双击启动脚本和模块入口。真实 API 调用由用户点击触发。
- 验证：离线测试任务隔离、凭证覆盖、取消、异常、快照失效；实际 Tk 窗口冒烟、全套 pytest、ruff 与构建。
