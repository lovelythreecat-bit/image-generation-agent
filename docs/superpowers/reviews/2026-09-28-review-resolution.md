| 编号 | 已落实的修正 | 规格位置 / 开发验收 |

| I1 required与镜头 | Requirement明确origin/applicability；用户和brief required按每资产执行，模型不能自定豁免。特写仅豁免默认非焦点要求；无法承载明确required则编译失败 | 规格5–6节；任务1/2/4/5A/6。must_show回not_applicable失败；不能整组都跳过杯盖 |

## 三项建议

| 建议 | 处理 |
| --- | --- |
| 前移供应商协议验证 | 任务3后核对官方资料并记录日期/能力未知项；未真实调用只声明离线协议通过。真实调用仍单独按范围验收，不凭fake证明容量 |
| 取消与落盘生命周期 | 生成阶段取消不保存部分；保留预留目录、下次新ID。纯计算线程等待清理；最终写盘shield并在取消退出前收尾，禁止请求返回后后台写入；CLI中断130 |
| 明确调用成本类别 | 单平台四资产无服装/风格/修复的自动模式10次逻辑调用，两阶段11次；服装补充、风格回退、复核与HTTP重试另计。109次仅是全平台生图上限 |
